MeshGenerator¶

Utility geometries for machining workflows.

This module provides small mesh-generation helpers (cylinders, cones, tori, ruled surfaces, heatmaps, etc.) built on top of trimesh. They are used throughout the point-milling notebooks to export STL assets, create Plotly visualizations, and reformat backend data for downstream processing.
